# bmi-calculator ⚖️

A clean BMI calculator supporting both metric and imperial units, with a visual scale and ideal weight range.

## Features

- Metric (cm/kg) and Imperial (ft/in/lbs) modes
- Animated scale marker
- Category label (Underweight / Normal / Overweight / Obese)
- Ideal weight range based on height
- Zero dependencies — open `index.html` and go
